1.1

Why This Topic Matters

RACEBig Picture Introduction

Every machine — a motor, a turbine, a robotic arm — has a desired output. But the real world is full of disturbances: loads change, temperatures drift, supply voltages fluctuate. If you just programme a machine and walk away (open-loop), it will drift, fail, or cause damage. Control Systems are the engineering answer to: how do we make any machine do exactly what we want, automatically, even as the world around it changes?

Without control theory, you cannot answer any of these engineering questions:

  • How do we keep grid frequency exactly at 50 Hz even as millions of fans switch on simultaneously? (Load Frequency Control)
  • How does a DC motor maintain 1500 rpm when load torque suddenly doubles? (Speed regulation)
  • How does an aircraft autopilot fly a fixed altitude against wind turbulence? (Disturbance rejection)
  • How does a solar inverter extract maximum power from panels despite cloud cover? (MPPT control)
  • How does an electric vehicle motor deliver precise torque in milliseconds? (Vector control)
🌍
Engineering Reality

India's power grid (1.5 million MW peak demand) keeps frequency within ±0.2 Hz of 50 Hz automatically — 24 hours a day, 365 days a year — using closed-loop control on hundreds of generators simultaneously. Without control theory, even a temporary 2% frequency deviation could cascade into a nationwide blackout, as happened to 700 million people in July 2012.

Intuitive Understanding

RACEIntuitive Explanation — Analogy First

The Thermostat — Closed-Loop Control

Imagine you set an AC to 25°C. The AC continuously measures room temperature, compares it to 25°C, and adjusts the compressor accordingly. This cycle — Sense → Compare → Correct — never stops. That is closed-loop control. The output (room temperature) feeds back to control the input (compressor power).

Fig 1.1 — Closed-loop temperature control. Output (room temperature) continuously feeds back to correct the error.

The Traffic Timer — Open-Loop Control

A traffic light that changes every 60 seconds, regardless of how many cars are waiting, is open-loop. It fires a pre-programmed sequence and never "looks" at the output. Simple, cheap, fast — but powerless against disturbance (sudden heavy traffic). This is the fundamental limitation of open-loop: accuracy depends entirely on the initial calibration holding true forever.

🔑
The Central Idea — One Structural Difference, Everything Changes

The only structural difference between open-loop and closed-loop is whether the output feeds back to influence the input. From this single difference emerge all the consequences: better accuracy, disturbance rejection, reduced sensitivity — and the new risk of instability. Understanding why these consequences follow from the structure is the foundation of control engineering.

⚠️
Exam Trap — Error vs Actuating Signal

Error e(t) = R(t) − C(t). Actuating signal = R(t) − B(t) = R(t) − H·C(t). Only when H(s) = 1 (unity feedback) are they equal. For non-unity feedback, they differ. GATE questions occasionally ask you to compute both separately — get the definition wrong and the numerical answer is wrong.

1.5

Transfer Function — Theory & Derivation

RACECore Theory + Mathematical Derivation

Definition & Physical Significance

The Transfer Function is the Laplace-domain ratio of output to input with all initial conditions set to zero. It is a property of the system, not the input — the same G(s) describes the system whether you apply a step, a ramp, or a sinusoid.

Transfer Function — Core Formula
$$G(s) = \left.\frac{C(s)}{R(s)}\right|_{\text{all IC} = 0} = \mathcal{L}[h(t)]$$ where $h(t)$ is the impulse response of the system.
#PropertyGATE / Exam Implication
1Valid only for LTI (Linear, Time-Invariant) systemsCannot apply TF to nonlinear or time-varying systems — linearise first
2Requires zero initial conditionsIf ICs ≠ 0, use full Laplace with IC terms — TF alone is insufficient
3Independent of input appliedSame G(s) for step, ramp, or impulse — it is a system property
4TF = ℒ[Impulse Response]Given h(t), find G(s) = ℒ[h(t)] — classic GATE question type
5Does not reveal internal statesPole-zero cancellation hides uncontrollable/unobservable modes — always investigate

Deriving the Closed-Loop Transfer Function (CLTF)

Step-by-Step Derivation from Block Diagram
$$C(s) = G(s) \cdot E(s) \quad \text{...(1) Forward path}$$ $$E(s) = R(s) - H(s) \cdot C(s) \quad \text{...(2) Comparator (negative feedback)}$$ $$\text{Substituting (2) into (1): } C(s) = G(s)[R(s) - H(s)C(s)]$$ $$C(s)[1 + G(s)H(s)] = G(s) \cdot R(s)$$ $$\boxed{T(s) = \frac{C(s)}{R(s)} = \frac{G(s)}{1 + G(s)H(s)}} \quad \text{← Negative Feedback}$$ $$\text{Positive feedback: } T(s) = \frac{G(s)}{1 - G(s)H(s)}$$

Effects of Negative Feedback

RACEQuantitative Analysis — The (1+GH) Factor

Every major system property is scaled by the factor (1 + GH) when negative feedback is applied. This single expression is the most important formula in classical control design.

💡
The Accuracy–Stability Trade-Off — The Central Challenge of Control Design

High loop gain GH → better accuracy, better disturbance rejection, reduced sensitivity to G. But beyond a critical gain, the loop gain becomes −1 at some frequency, driving the system into oscillation. Every real-world control design is fundamentally the art of pushing gain as high as possible while keeping adequate stability margin. This trade-off is the core theme of Chapters 4–7.

1.8

Sensitivity Analysis

RACEWhy Sensors Must Be Precision Components
Sensitivity Definition and CLTF Sensitivity Formulas
$$S_G^T = \frac{\partial T/T}{\partial G/G} = \frac{G}{T} \cdot \frac{\partial T}{\partial G}$$ $$\text{For standard CL system: } S_G^T = \frac{1}{1 + G(s)H(s)} \rightarrow 0 \text{ as } GH \rightarrow \infty$$ $$S_H^T = \frac{-G(s)H(s)}{1 + G(s)H(s)} \rightarrow -1 \text{ as } GH \rightarrow \infty$$
🔑
The Single Most Important Insight in This Chapter

Negative feedback makes the closed-loop insensitive to forward-path variations (S_G^T → 0) — so the plant can be imprecise, old, or even mildly nonlinear. But it makes the system completely sensitive to the feedback element (S_H^T → −1). A 2% error in the tachometer causes exactly 2% speed error. This is why sensors and CTs/PTs in power systems must be the highest-quality components in the loop.

1.9

Concept Building Questions

RACETeach Yourself by Questioning
CBQ Set — Control System Fundamentals
Q1. Why does negative feedback reduce gain? Isn't that bad for performance?
Gain drops by (1+GH). But you gain stability, bandwidth, and immunity from parameter drift. An op-amp with open-loop gain of 100,000 is useless for precision — it varies 50× with temperature. With negative feedback, gain becomes 10 — stable, repeatable, temperature-immune. An engineer always trades raw gain for reliability. This is not a loss; it is a deliberate, value-adding design decision.
Q2. What happens practically when loop gain GH → ∞?
T(s) → 1/H(s). The closed-loop response becomes determined entirely by the feedback element, not the plant. This is powerful — a noisy, old plant can be used inside a precision loop. However, in any real physical system, every pole has some phase shift; as gain increases, eventually the total loop phase shift reaches −180° and the system oscillates. Infinite gain is never practically achievable without instability.
Q3. Why is the sensor the most critical component in a closed-loop system?
Because S_H^T → −1. A 1% error in the sensor causes exactly 1% error in the system output — with zero ability for the loop to correct it. The system trusts the sensor completely. The plant can be 50% inaccurate (the loop corrects it), but the sensor cannot be wrong. This is why industrial servos use 17-bit absolute encoders, power grids use 0.1-class CTs and PTs, and medical instruments use calibrated precision transducers.
Q4. An open-loop system is always stable. Does closing the loop always make it unstable?
No. For most stable plants with reasonable gain, closing the loop improves stability (by reducing oscillations through error correction). Instability requires the loop gain GH = −1, which only happens when gain is too high or phase lag is too large. Many inherently unstable plants (like an inverted pendulum or a modern fighter aircraft) can only be made to work with closed-loop control — open-loop is hopelessly unstable for them.
Q5. If you see a pole-zero cancellation in the closed-loop transfer function, should you ignore it?
Never. A pole-zero cancellation means the system is either uncontrollable, unobservable, or both. The cancelled mode still exists physically — it can be excited by initial conditions — but the controller cannot see it or correct it. If it is an unstable mode, it will grow invisibly until the machine fails. Always investigate cancellations before accepting a transfer function.

Time-Saving Shortcuts

⚡
Shortcut 1 — Sensitivity of T = aK/(b+cK)

If T = aK/(b+cK), then S_K^T = b/(b+cK). Derivation in 5 seconds: numerator = only term without K = b. Denominator = b+cK. Done. This pattern appears in ~80% of GATE sensitivity problems.

⚡
Shortcut 2 — Impulse Response to OLTF in 30 Seconds

Given impulse response c(t) of a unity feedback system: Step 1: T(s) = ℒ[c(t)]. Step 2: G = T/(1−T). Do the algebra in s-domain only — never go back to time domain.

Worked Examples

RACEBasic → GATE-Level → Conceptual
BASICConverting a Differential Equation to Transfer Function
Given the system differential equation: 3ÿ + 7ẏ + 2y = 5u̇ + u where u is input, y is output. Find G(s) = Y(s)/U(s).
Solution — Step by Step
Step 1: Take Laplace transform of both sides with zero initial conditions. $$3s^2Y(s) + 7sY(s) + 2Y(s) = 5sU(s) + U(s)$$ Step 2: Factor out Y(s) and U(s). $$Y(s)(3s^2 + 7s + 2) = U(s)(5s + 1)$$ Step 3: Write the Transfer Function. $$\boxed{G(s) = \frac{Y(s)}{U(s)} = \frac{5s + 1}{3s^2 + 7s + 2} = \frac{5s + 1}{(3s + 1)(s + 2)}}$$
⚠️
Always Check for Pole-Zero Cancellation

The zero at s = −0.2 does not cancel with poles at s = −1/3 or s = −2. If it did, that cancelled mode would be uncontrollable or unobservable — a masked internal instability. Always factorise and verify before accepting the TF.

GATE LEVELRecovering OLTF from Closed-Loop Impulse Response
The unit impulse response of a unity negative feedback closed-loop system is c(t) = 4e⁻²ᵗ − 3e⁻³ᵗ, t ≥ 0. Find the open-loop transfer function G(s).
Solution — Step by Step
Step 1: Since the input is an impulse (R(s) = 1), C(s) = T(s)·1 = T(s). $$T(s) = \mathcal{L}[c(t)] = \frac{4}{s+2} - \frac{3}{s+3} = \frac{4(s+3) - 3(s+2)}{(s+2)(s+3)} = \frac{s+6}{(s+2)(s+3)}$$ Step 2: Apply unity feedback recovery formula. $$1 - T(s) = 1 - \frac{s+6}{(s+2)(s+3)} = \frac{(s+2)(s+3) - (s+6)}{(s+2)(s+3)} = \frac{s^2+5s+6-s-6}{(s+2)(s+3)} = \frac{s^2+4s}{(s+2)(s+3)} = \frac{s(s+4)}{(s+2)(s+3)}$$ $$\boxed{G(s) = \frac{T}{1-T} = \frac{s+6}{s(s+4)}}$$
⛔
The Classic GATE Trap

The formula is G = T/(1−T). The most common error is G = T/(1+T). Verify your answer: substitute G = (s+6)/[s(s+4)] back into G/(1+G) and check you recover T(s) = (s+6)/[(s+2)(s+3)].

CONCEPTUALSensitivity Analysis — Design a Stable Gain
A closed-loop transfer function is T(K) = 6K / (5 + 8K). Find S_K^T. If K changes by +10%, what is the resulting change in T?
Solution — Step by Step
Step 1: Apply S_K^T = (K/T)·(dT/dK). $$\frac{dT}{dK} = \frac{(5+8K)(6) - 6K(8)}{(5+8K)^2} = \frac{30}{(5+8K)^2}$$ $$S_K^T = \frac{K}{\frac{6K}{5+8K}} \cdot \frac{30}{(5+8K)^2} = \frac{K(5+8K)}{6K} \cdot \frac{30}{(5+8K)^2} = \frac{30}{6(5+8K)} = \frac{5}{5+8K}$$ Step 2: Use shortcut pattern verification — T = aK/(b+cK) → S_K^T = b/(b+cK) = 5/(5+8K). ✓

Step 3: % change in T = S_K^T × % change in K = [5/(5+8K)] × 10%. At K=1: S = 5/13 = 0.385 → T changes by 0.385 × 10% = 3.85% (feedback reduces K sensitivity from 10% to 3.85%).

Memory Tricks & Quick Revision Sheet

RACEMemory Techniques + One-Page Revision
🧠 Memory Techniques
Effects of Negative Feedback — "GBST-NE"
Gain decreases, Bandwidth increases, Sensitivity to G decreases, Time constant decreases, Noise output decreases, Error reduces. Phrase: "Good Boys Study Till Night Ends"
Recovery Formula — "The Negative One"
G = T/(1−T) for unity negative feedback. The minus in "negative" feedback appears in the denominator as (1 − T). Not (1+T). Never (1+T).
Sensitivity Rule — "Forward is Safe, Feedback is Fatal"
S to G (forward path) → 0 as GH → ∞. Plant can be cheap and imprecise. S to H (feedback path) → −1. Sensor errors pass 1:1 to output — no correction possible. Always use precision sensors.
The Wise Archer vs The Blind Archer
Open-loop = a blind archer: fixes aim, releases arrow, never adjusts. Accurate only in ideal, still conditions. Closed-loop = a wise archer: watches where arrows land (feedback), measures miss distance (error), adjusts aim (control action), fires again. Hits target in wind — but can overcorrect and oscillate (instability).
TF Conditions — "LTI + Zero IC"
Linear + Time-Invariant + Zero Initial Conditions = TF valid. If any of these three conditions fail, use state-space or direct differential equations.
