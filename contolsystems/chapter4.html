Stability Analysis

A system that is accurate but unstable is worse than useless — it's dangerous. Stability analysis answers the fundamental question: will this system's output remain bounded when the input is bounded? This chapter covers the algebraic Routh–Hurwitz criterion, BIBO stability, marginal stability, and system type classification — all heavy-hitters in GATE and IES exams.

4.1

What is Stability?

A system is said to be stable if, for every bounded input, the output also remains bounded. This is the formal BIBO (Bounded Input, Bounded Output) definition of stability used in GATE.

✅ Stable System
  • All poles in the Left Half of S-plane (LHP)
  • Transient response → 0 as t→∞
  • Bounded input produces bounded output
  • All roots of CE have negative real parts
❌ Unstable System
  • Any pole in the Right Half of S-plane (RHP)
  • Output grows without bound
  • Characteristic equation has roots with positive real part
  • Even small inputs cause diverging response
⚡ Marginally Stable System
  • Poles lie on the imaginary axis (purely imaginary roots)
  • Output oscillates continuously — neither grows nor decays
  • Called "marginally stable" or "critically stable"
  • Practically: NOT acceptable — any perturbation causes instability
4.2

Stability & the S-Plane

The location of closed-loop poles in the s-plane completely determines whether a system is stable, unstable, or marginally stable. This is the geometric interpretation of stability.

You don't need to solve for poles to determine stability. The Routh–Hurwitz criterion gives you stability information directly from the characteristic equation coefficients — without finding the roots. This is why it's so powerful for GATE problems involving symbolic gain values.
4.3

Routh–Hurwitz Criterion

The Routh–Hurwitz criterion is an algebraic method to determine stability without computing roots. It works by analysing the sign pattern of elements in a specially constructed array called the Routh Array.

$$ a_ns^n + a_n₋₁s^n⁻¹ + ... + a₁s + a₀ = 0 $$

Necessary Conditions for Stability

Before building the Routh array, check these quick conditions. If either fails, the system is definitely unstable:

  • All coefficients must be present — no missing (zero) coefficients for intermediate powers of s.
  • All coefficients must have the same sign — all positive or all negative. Any sign change = guaranteed instability.
⚠️ Necessary but NOT Sufficient
These two conditions are necessary for stability but not sufficient. A polynomial can pass both checks and still be unstable — that's why we need the full Routh Array analysis as the sufficient condition.
4.4

Constructing the Routh Array

Given CE: $$ a_ns^n + a_n₋₁s^n⁻¹ + a_n₋₂s^n⁻^2 + ... + a₁s + a₀ = 0 $$, the array is built as follows:

  • Row 1: Write alternate coefficients starting from aₙ — i.e., aₙ, aₙ₋₂, aₙ₋₄, ...
  • Row 2: Write the remaining alternate coefficients — i.e., aₙ₋₁, aₙ₋₃, aₙ₋₅, ...
  • Subsequent rows: Each element is computed from the 2×2 determinant of the two rows above it, divided by the leftmost element of the row immediately above.

4.5

Special Cases in Routh Array

Case 1: Zero in First Column Only
  • Replace the zero with a small positive ε → 0⁺
  • Complete the array using ε
  • Check sign changes as ε → 0
  • Alternatively: substitute s = 1/z and solve new CE
  • System is either marginally stable or unstable
Case 2: Entire Row of Zeros
  • Indicates presence of symmetric roots
  • These roots are equidistant from origin in S-plane
  • Form Auxiliary Polynomial from the row ABOVE the zero row
  • Replace zero row with derivative of auxiliary polynomial
  • Roots of auxiliary polynomial are the symmetric roots
💡 Auxiliary Polynomial Insight
When an entire row is zero (Case 2), the Auxiliary Polynomial A(s) is formed from the row above it. The degree of A(s) is even (2, 4, 6...). Its roots always occur in pairs symmetric about the origin — e.g., ±jω, ±σ, or ±(σ+jω) with ±(−σ−jω). This directly reveals marginal stability when roots are ±jω.
4.6

System Type & Error Constants

The system type is determined by the number of pure integrators (poles at s=0) in the open-loop transfer function G(s). Higher system type → lower steady-state error, but at the cost of stability.

🚨 Critical Note — Type vs Stability
Increasing system type always improves steady-state accuracy — but it simultaneously reduces phase margin and makes the system harder to stabilise. The Routh-Hurwitz criterion helps you find exactly which gain values keep a higher-type system stable.

Finding Frequency of Sustained Oscillation

When a system is at the boundary of stability (marginal), sustained oscillations occur at a specific frequency. This is found by substituting $$ s = j\omega $$ into the characteristic equation and solving for ω where the CE = 0.

$$ At stability boundary: substitute s = j\omega in CE $$
Separate real and imaginary parts → set both = 0 → solve for ω and K simultaneously
🤖 Aarova AI — Worked Method
For CE: s³ + 6s² + 11s + K = 0, at marginal stability the s¹ row element = 0:
(66 − K)/6 = 0 → K = 66 (limiting gain).
Auxiliary poly from s² row: 6s² + K = 6s² + 66 → s² = −11 → s = ±j√11
ωₒₛc = √11 ≈ 3.32 rad/s. This is the exact frequency of oscillation at the stability boundary.
4.7

GATE & IES Exam Concepts

CONCEPT 1The Non-Unity Feedback Error Trap

The standard steady-state error formulas (\( e_{ss} = 1/(1+K_p) \) or \( 1/K_v \)) are derived under the assumption of unity feedback (\( H(s) = 1 \)). When \( H(s) \neq 1 \), applying these formulas directly is incorrect. You must use one of two correct approaches:

Method 1: Direct FVT on Output Error

Define physical error as \( e(t) = r(t) - c(t) \). Find the CLTF \( T(s) = C(s)/R(s) \) first: $$ E(s) = R(s)[1 - T(s)] $$ Apply the Final Value Theorem directly: $$ e_{ss} = \lim_{s\to 0} s E(s) = \lim_{s\to 0} s R(s)[1 - T(s)] $$

Method 2: Unity Feedback Equivalence

Convert the non-unity feedback system into an equivalent unity feedback system with a new forward path transfer function: $$ G_{eq}(s) = \frac{G(s)}{1 + G(s)(H(s) - 1)} $$ Once \( G_{eq}(s) \) is found, apply standard error constants to it.

⛔
Exam Trap

Never compute static error constants using the open-loop transfer function \( G(s)H(s) \) directly if \( H(s) \neq 1 \). This mistake is tested in many GATE electrical and electronics papers.

CONCEPT 2Routh Array Special Cases and Physical Interpretations

The Routh array construction has two singular cases that require special mathematical treatment:

  • Case 1: First Element of a Row is Zero (but other terms are non-zero)
    Replace the zero with a small positive number \( \epsilon \) and proceed to construct the rest of the array. Once complete, take the limit \( \epsilon \to 0^+ \) to analyze sign changes in the first column.
  • Case 2: A Complete Row of Zeros
    This indicates the existence of roots located symmetrically about the origin in the \(s\)-plane (e.g., imaginary axis roots \( \pm j\omega \), real axis roots \( \pm \sigma \), or complex conjugate pairs). To continue:
    1. Form the Auxiliary Equation \( A(s) = 0 \) using the row immediately above the zero row.
    2. Take the derivative of the auxiliary equation with respect to \( s \): \( \frac{dA(s)}{ds} \).
    3. Replace the zero row with the coefficients of the derivative and proceed.
⚖️
Stability Interpretation

A complete row of zeros means the system has symmetric roots. If there are no sign changes in the first column of the completed Routh array, the system is marginally stable (sustained oscillations), and all symmetric roots lie on the imaginary axis.

CONCEPT 3Marginal Gain and Frequency of Oscillation

When the characteristic equation contains an adjustable gain parameter \( K \), Routh-Hurwitz helps find the boundaries of stability:

  • Find the range of \( K \) for stability by setting all terms in the first column of the Routh array to be greater than zero (\( > 0 \)).
  • The boundary value of \( K \) that causes a row to become zero is the marginal gain (\( K_{mar} \)).
  • To find the **frequency of sustained oscillation** at this boundary, substitute \( K = K_{mar} \) into the auxiliary equation \( A(s) = 0 \) and solve for \( s = \pm j\omega_{osc} \).
4.8

Worked Examples (GATE & IES)

Example 01
Stability Range & Frequency of Sustained Oscillation

A unity feedback control system is described by the open-loop transfer function \( G(s) = \frac{K}{s(s+3)(s+5)} \). Determine the range of \( K \) for stability, the marginal gain \( K_{mar} \), and the frequency of sustained oscillation when the system is marginally stable.

Solution
1. Characteristic Equation (CE):
$$ 1 + G(s)H(s) = 0 \implies 1 + \frac{K}{s(s+3)(s+5)} = 0 $$ $$ s(s^2 + 8s + 15) + K = 0 \implies s^3 + 8s^2 + 15s + K = 0 $$
2. Construct Routh Array:
s³  |  1         15
s²  |  8         K
s¹  |  \(\frac{120 - K}{8}\)     0
s⁰  |  K
3. Apply Stability Conditions:
For stability, all elements in the first column must be strictly positive (> 0): $$ \text{Row } s^1: \quad \frac{120 - K}{8} > 0 \implies K < 120 $$ $$ \text{Row } s^0: \quad K > 0 $$ Thus, the stability range is: \( 0 < K < 120 \).
4. Find marginal gain and frequency of oscillation:
At boundary of stability: \( K_{mar} = 120 \). The row above (\( s^2 \)) forms the auxiliary equation: $$ 8s^2 + K_{mar} = 0 \implies 8s^2 + 120 = 0 $$ $$ s^2 = -\frac{120}{8} = -15 \implies s = \pm j\sqrt{15} \approx \pm j3.87 \text{ rad/s} $$ The frequency of sustained oscillation is \( \omega_{osc} = \sqrt{15} \approx \mathbf{3.87 \text{ rad/s}} \).
✔ Ans: Range: \( 0 < K < 120 \), \( K_{mar} = 120 \), \( \omega_{osc} = 3.87 \text{ rad/s} \)
Example 02
Handling first-column zero via \(\epsilon\)-substitution

Determine the stability of a system whose characteristic equation is given by: $$ s^4 + 2s^3 + 2s^2 + 4s + 8 = 0 $$

Solution
1. Construct Routh Array:
The first two rows are filled directly from the coefficients:
s⁴  |  1     2     8
s³  |  2     4     0       (simplify: divide by 2 → 1, 2, 0)
Compute \( s^2 \) row: $$ s^2 \text{ first term} = \frac{1(2) - 1(2)}{1} = 0 $$ Since the first term is zero but other elements are not, we replace it with \( \epsilon \):
s²  |  \(\epsilon\)     8
s¹  |  \(\frac{2\epsilon - 8}{\epsilon}\)     0
s⁰  |  8
2. Analyze Sign Changes in the First Column:
Evaluate the first column elements as \( \epsilon \to 0^+ \):
  1. \( s^4 \) row term: \( 1 \) (Positive)
  2. \( s^3 \) row term: \( 1 \) (Positive)
  3. \( s^2 \) row term: \( \epsilon \approx 0^+ \) (Positive)
  4. \( s^1 \) row term: \( \lim_{\epsilon\to 0^+} \frac{2\epsilon-8}{\epsilon} \approx -\infty \) (Negative!)
  5. \( s^0 \) row term: \( 8 \) (Positive)
The first column signs are: \( +, +, +, -, + \).
3. Conclude on Stability and Pole Count:
There are two sign changes (\( + \to - \) and \( - \to + \)) in the first column. Therefore, there are 2 closed-loop poles in the Right Half of the s-plane (RHP). The system is unstable.
✔ Ans: Unstable, 2 poles in RHP
Example 03
Steady-State Error of a Non-Unity Feedback System

A feedback control system has a forward path transfer function \( G(s) = \frac{10}{s(s+2)} \) and feedback path transfer function \( H(s) = 0.5s + 1 \). Compute the steady-state output error \( e_{ss} = \lim_{t\to\infty} [r(t) - c(t)] \) when the system is excited by a unit ramp input \( r(t) = t\,u(t) \).

Solution
1. Identify Closed-Loop Transfer Function \( T(s) \):
Since \( H(s) \neq 1 \), we must first find \( T(s) = C(s)/R(s) \): $$ T(s) = \frac{G(s)}{1 + G(s)H(s)} = \frac{\frac{10}{s(s+2)}}{1 + \frac{10(0.5s + 1)}{s(s+2)}} $$ $$ T(s) = \frac{10}{s(s+2) + 10(0.5s + 1)} = \frac{10}{s^2 + 2s + 5s + 10} = \frac{10}{s^2 + 7s + 10} $$
2. Formulate the Error Transfer Function:
The output error in the frequency domain is: $$ E(s) = R(s) - C(s) = R(s)[1 - T(s)] $$ $$ E(s) = R(s)\left[1 - \frac{10}{s^2 + 7s + 10}\right] = R(s)\left[\frac{s^2 + 7s}{s^2 + 7s + 10}\right] = R(s)\left[\frac{s(s+7)}{s^2 + 7s + 10}\right] $$
3. Apply Final Value Theorem for Unit Ramp Input:
For unit ramp input, \( R(s) = 1/s^2 \). $$ E(s) = \frac{s(s+7)}{s^2 + 7s + 10} \cdot \frac{1}{s^2} = \frac{s+7}{s(s^2 + 7s + 10)} $$ Using FVT to find steady-state error: $$ e_{ss} = \lim_{s\to 0} s E(s) = \lim_{s\to 0} \left[ s \cdot \frac{s+7}{s(s^2 + 7s + 10)} \right] $$ $$ e_{ss} = \lim_{s\to 0} \frac{s+7}{s^2 + 7s + 10} = \frac{0+7}{0+0+10} = \mathbf{0.7} $$
✔ Ans: Steady-state error \( e_{ss} = 0.7 \)
4.9

Chapter Summary

🔑 Routh–Hurwitz Rules
  • Necessary Condition: All CE coefficients must be present and have the same sign.
  • Sufficient Condition: No sign changes in the first column of the Routh array.
  • Sign Changes: Number of sign changes in the first column = number of RHP poles.
  • Zero first term: Replace with \( \epsilon \) and proceed.
  • Zero Row: Symmetric poles exist. Use auxiliary polynomial \( A(s) \).
📊 Stability Summary
  • Stable: All closed-loop poles in LHP.
  • Unstable: Any pole in RHP.
  • Marginally Stable: Simple, non-repeated poles on imaginary axis, others in LHP.
  • Marginal gain \( K_{mar} \): Gain boundary where row of zeros occurs.
  • Oscillation Frequency: Determined by solving auxiliary equation \( A(s) = 0 \) at \( K_{mar} \).
🤖 Aarova AI — Chapter Takeaway
Stability analysis is the absolute baseline of control engineering. Accuracy and speed are meaningless if the system runs wild. The algebraic Routh–Hurwitz criterion serves as a quick tool to bound system gain and evaluate absolute stability without computing roots, laying the groundwork for root-locus-based gain selection.
