8.1

Introduction to State Space

Classical control theory relies heavily on the Laplace transform and transfer functions. However, transfer functions are limited to linear, time-invariant (LTI), single-input single-output (SISO) systems with zero initial conditions. State Space Analysis overcomes all these limitations by using a generalized time-domain matrix approach.

State Variables & Vector

State Variables (\(x_1, x_2, \dots x_n\)): The minimum set of variables required to completely determine the future behavior of the system, given the present state and future inputs.

State Vector (\(X\)): An \(n \times 1\) column matrix containing all the state variables.

Number of State Variables

The number of state variables required to describe a system equals the number of independent energy storage elements (e.g., capacitors, inductors) or the order of the denominator polynomial (poles) in its transfer function.

8.2

State Space Representation (SSR)

A dynamic system is represented by two primary matrix equations: the State Equation (which describes the internal dynamics) and the Output Equation (which maps states and inputs to the measured output).

State Equation
$$ \dot{X}(t) = A X(t) + B U(t) $$
Output Equation
$$ Y(t) = C X(t) + D U(t) $$

Where:

  • \( X(t) \): State Vector (\(n \times 1\))
  • \( U(t) \): Input Vector (\(m \times 1\))
  • \( Y(t) \): Output Vector (\(p \times 1\))
  • \( A \): System Matrix (\(n \times n\))
  • \( B \): Input Matrix (\(n \times m\))
  • \( C \): Output Matrix (\(p \times n\))
  • \( D \): Direct Transmission Matrix (\(p \times m\))

Transfer Function from SSR

By taking the Laplace transform of the state and output equations (assuming zero initial conditions) and solving for \( Y(s)/U(s) \), we obtain the transfer function matrix:

Transfer Function
$$ TF = \frac{Y(s)}{U(s)} = C(sI - A)^{-1}B + D $$
Here, \( |sI - A| = 0 \) yields the characteristic equation, and its roots are the eigenvalues of matrix A (the system poles).

8.3

Canonical Forms

A single transfer function can be represented by an infinite number of state space models depending on the choice of state variables. However, we standardise them into specific Canonical Forms for easy analysis.

1. Controllable Canonical Form (CCF)

In this form, the coefficients of the transfer function denominator directly populate the bottom row of matrix A (with negative signs), and matrix B is a column vector with a 1 at the bottom.

2. Observable Canonical Form (OCF)

This is the dual of the CCF. Matrix A is the transpose of the A matrix from CCF. The transfer function coefficients populate the last column of A, and matrix C is a row vector with a 1 at the end.

3. Diagonal Canonical Form (DCF)

Used when the system has distinct, non-repeated poles. By performing partial fraction expansion on the transfer function, matrix A becomes a purely diagonal matrix where the diagonal elements are the system poles (eigenvalues). Matrices B and C consist of 1s and partial fraction residues.

4. Jordan Canonical Form (JCF)

Used when the system has repeated poles. Matrix A contains Jordan blocks along the diagonal. A Jordan block has the repeated pole on the main diagonal and 1s on the super-diagonal.

8.4

State Transition Matrix (STM)

The State Transition Matrix, denoted as \( \phi(t) \) or \( e^{At} \), dictates how the internal state of an unforced system (zero input) transitions from its initial state \( X(0) \) to any future state \( X(t) \).

Calculation of STM
$$ \phi(t) = e^{At} = L^{-1} [ (sI - A)^{-1} ] $$
Properties of STM
  • \( \phi(0) = I \) (Identity Matrix)
  • \( \phi^{-1}(t) = \phi(-t) \)
  • \( \phi(t_1 + t_2) = \phi(t_1) \phi(t_2) \)
  • \( [\phi(t)]^k = \phi(kt) \)
Total Response

The complete time response of the state vector is the sum of the Zero Input Response and the Zero State Response:

\( X(t) = \phi(t)X(0) + \int_{0}^{t} \phi(t-\tau)B U(\tau) d\tau \)

8.5

Controllability & Observability

Controllability: A system is controllable if it is possible to transfer the system from any initial state to any desired final state within a finite time interval by applying an unconstrained control input vector \( U(t) \).

Observability: A system is observable if it is possible to determine the initial state vector \( X(0) \) by observing the output vector \( Y(t) \) over a finite time interval.

Kalman's Test for Controllability

Construct the Controllability Matrix \( Q_c \). For an \( n \times n \) system matrix A:

$$ Q_c = \begin{bmatrix} B & AB & A^2B & \dots & A^{n-1}B \end{bmatrix} $$
The system is controllable if and only if the determinant \( |Q_c| \neq 0 \) (i.e., it has full rank \( n \)).

Kalman's Test for Observability

Construct the Observability Matrix \( Q_o \):

$$ Q_o = \begin{bmatrix} C^T & A^T C^T & (A^T)^2 C^T & \dots & (A^T)^{n-1} C^T \end{bmatrix} $$
The system is observable if and only if the determinant \( |Q_o| \neq 0 \) (i.e., it has full rank \( n \)).
8.6

GATE & IES Exam Concepts

CONCEPT 1Uniqueness of Transfer Functions vs. SSR

A specific system has a unique transfer function. However, the same system can have an infinite number of State Space Representations depending on how the state variables are chosen (e.g., CCF, OCF, physical variables).

CONCEPT 2Pole-Zero Cancellation

If you convert a state space model into a transfer function \( C(sI-A)^{-1}B + D \), and you notice a pole-zero cancellation occurs, it implies that the system is either uncontrollable, unobservable, or both. A fully controllable and observable system will never have pole-zero cancellations in its transfer function.

8.7

Worked Examples (GATE & IES)

Example 01
Transfer Function to Controllable Canonical Form

Obtain the Controllable Canonical Form (CCF) for the system defined by the transfer function \( \frac{Y(s)}{U(s)} = \frac{4s + 10}{s^3 + 6s^2 + 11s + 6} \).

Solution
1. Identify the coefficients:
Denominator: \( s^3 + a_2 s^2 + a_1 s + a_0 \implies a_2=6, a_1=11, a_0=6 \).
Numerator: \( b_2 s^2 + b_1 s + b_0 \implies b_2=0, b_1=4, b_0=10 \).
2. Construct the A matrix (CCF format):
The bottom row contains the negative of the denominator coefficients starting from \( a_0 \).
$$ A = \begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 1 \\ -6 & -11 & -6 \end{bmatrix} $$
3. Construct B and C matrices:
B is standard for CCF, C contains numerator coefficients.
$$ B = \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}, \quad C = \begin{bmatrix} 10 & 4 & 0 \end{bmatrix} $$
✔ Ans: A, B, and C matrices derived successfully using CCF rules.
Example 02
Calculation of State Transition Matrix (STM)

Calculate the State Transition Matrix \( \phi(t) \) for a system matrix \( A = \begin{bmatrix} 0 & 1 \\ -2 & -3 \end{bmatrix} \).

Solution
1. Find the resolvent matrix \( (sI - A) \):
$$ (sI - A) = \begin{bmatrix} s & -1 \\ 2 & s+3 \end{bmatrix} $$
2. Find the inverse \( (sI - A)^{-1} \):
Determinant: \( \Delta = s(s+3) - (-2) = s^2 + 3s + 2 = (s+1)(s+2) \).
Adjoint: swap diagonals, flip signs on off-diagonals.
$$ (sI - A)^{-1} = \frac{1}{(s+1)(s+2)} \begin{bmatrix} s+3 & 1 \\ -2 & s \end{bmatrix} $$
3. Apply Partial Fractions & Inverse Laplace:
Element (1,1): \( \frac{s+3}{(s+1)(s+2)} = \frac{2}{s+1} - \frac{1}{s+2} \implies 2e^{-t} - e^{-2t} \)
Element (1,2): \( \frac{1}{(s+1)(s+2)} = \frac{1}{s+1} - \frac{1}{s+2} \implies e^{-t} - e^{-2t} \)
Element (2,1): \( \frac{-2}{(s+1)(s+2)} = \frac{-2}{s+1} + \frac{2}{s+2} \implies -2e^{-t} + 2e^{-2t} \)
Element (2,2): \( \frac{s}{(s+1)(s+2)} = \frac{-1}{s+1} + \frac{2}{s+2} \implies -e^{-t} + 2e^{-2t} \)
✔ Ans: \( \phi(t) = \begin{bmatrix} 2e^{-t} - e^{-2t} & e^{-t} - e^{-2t} \\ -2e^{-t} + 2e^{-2t} & -e^{-t} + 2e^{-2t} \end{bmatrix} \).
Example 03
Checking Controllability using Kalman's Test

Given a system defined by \( A = \begin{bmatrix} 0 & 1 \\ -1 & -2 \end{bmatrix} \) and \( B = \begin{bmatrix} 1 \\ -1 \end{bmatrix} \). Determine if the system is completely state controllable.

Solution
1. Construct Controllability Matrix \( Q_c \):
Since it's a 2x2 matrix (n=2), \( Q_c = \begin{bmatrix} B & AB \end{bmatrix} \).
We already have B. Now find AB:
$$ AB = \begin{bmatrix} 0 & 1 \\ -1 & -2 \end{bmatrix} \begin{bmatrix} 1 \\ -1 \end{bmatrix} = \begin{bmatrix} -1 \\ 1 \end{bmatrix} $$
2. Assemble \( Q_c \) and find its determinant:
$$ Q_c = \begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix} $$
$$ |Q_c| = (1)(1) - (-1)(-1) = 1 - 1 = 0 $$
3. Conclusion:
Because the determinant of \( Q_c \) is exactly zero, the matrix does not have full rank. The system is uncontrollable.
✔ Ans: $|Q_c| = 0$. The system is UNCONTROLLABLE.
