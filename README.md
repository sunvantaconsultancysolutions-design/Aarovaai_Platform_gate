# Aarova AI — GATE & IES Study Platform

A comprehensive, exam-focused study platform built for GATE EE, GATE EC, IES E&T, and PSU examinations. This repository contains the static web pages and chapter-wise study notes for multiple core electrical engineering subjects.

## Subjects Included

- **Control Systems:** Time response, root locus, and frequency domains.
- **Electrical Measurements:** Bridges, potentiometers, instrument transformers, and error analysis.
- **Electrical Machines:** Transformers, DC Machines, Synchronous Machines, and Induction Motors.
- **Power Systems:** Generation, transmission lines, load flow, and fault analysis.
- **Power Electronics:** Inverters, rectifiers, choppers, and switching devices.

## Features

- **Exam-Ready Concepts:** Chapter-wise notes with GATE-type worked examples and formula references.
- **Works Offline:** Built purely with HTML, CSS, and vanilla JavaScript. No internet or server is required to view the content once loaded locally.
- **Responsive Design:** A beautiful and functional UI designed to work seamlessly across desktop and mobile devices.

## How to Run Locally

Since this is a static website, you don't need to install any dependencies. Simply clone the repository and open `index.html` in your web browser:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME
```
Then, double-click `index.html` or serve it using a local server (like Live Server in VS Code, or `npx serve`).

## Deployment

This website is designed to be hosted effortlessly on **GitHub Pages**. 
Go to your repository settings -> Pages -> Build and deployment -> Source: Deploy from a branch -> Select `main` -> Save.
